# Mi API con FastAPI y Python

## Descripción
API REST desarrollada con **FastAPI** y **Python** como parte de una actividad 
práctica de desarrollo backend. La API permite consultar ítems mediante 
endpoints GET, e incluye documentación interactiva automática generada por 
FastAPI. Fue probada desde el navegador, la terminal con `curl` y Postman.

## Tecnologías usadas
- Python 3.x
- FastAPI
- Uvicorn (servidor ASGI)

## Requisitos previos
- Python 3.x instalado
- pip disponible en el sistema
